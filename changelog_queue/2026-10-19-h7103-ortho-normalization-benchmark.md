- **H7103: a 200-token de/ru historical-normalization benchmark with source-line grounding, frozen splits, a rule-map baseline and a dataset card (fail-path scope: no scan claim).** New `data/ortho/gold.tsv` freezes 100 German pre-reform gloss tokens (25 each from PWG, PWK, CCS, SCH) and 100 pre-1918 Russian tokens (Kossovich), each carrying source file, 1-based line, context, historical token, modern target, reform era and `scan_verified=false`; `data/ortho/candidates.tsv` carries the honest residual (all 200 rows, reason: source-text-grounded only, no page image opened). Splits are **100 train / 50 dev / 50 test**, stratified by dictionary, with a fixed seed and manifest sha256. Targets come from the frozen SanskritSpellCheck reform maps, consumed read-only and not redistributed. Baseline (generic `th→t`, `ß→ss`, `-iren→-ieren`; `ѣ→е`, `і→и`, `ѳ→ф`, `ѵ→и`, final `ъ` dropped): **84.5 % accuracy / 15.5 % WER / CER 0.0193**, 95 % bootstrap CI [79.5, 89.5] accuracy (German 69.0 % / 0.0363, Russian 100 % / 0) against a 0.5 % identity floor; the map-lookup ceiling is 100 % by construction and labelled as such. Metrics follow Bollmann (2019, N19-1389) at token level. `npm run build-ortho-benchmark` rebuilds from sibling checkouts; `npm run score-ortho-benchmark` re-checks the committed baseline or scores an `id<TAB>prediction` TSV. Six tests pin counts, uniqueness, hash, split ratios, rule cases, WER/CIs, baseline agreement and the rights/grounding caveats. Grounding is source-text-level, **not scan-image verified**; Russian is single-dictionary (KOW, 1854) — both stated in `data/ortho/normalization_benchmark.card.md`, `docs/ORTHO_BENCHMARK.md` and on the `/tools/ortho-drift` page.
