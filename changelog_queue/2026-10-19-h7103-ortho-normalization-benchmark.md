- **H7103: a 200-token de/ru historical-normalization benchmark with source-line grounding, splits, a rule-map baseline and a dataset card.** New `data/ortho/normalization_benchmark.gold.tsv` freezes 100 German pre-reform gloss tokens (25 each from PWG, PWK, CCS, SCH) and 100 pre-1918 Russian tokens (Kossovich), each carrying source file, 1-based line, context, historical token, modern target and reform era; splits are 120 train / 40 dev / 40 test. Targets come from the frozen SanskritSpellCheck reform maps, consumed read-only and not redistributed. Baseline (generic `th→t`, `ß→ss`, `-iren→-ieren`; `ѣ→е`, `і→и`, `ѳ→ф`, `ѵ→и`, final `ъ` dropped): **84.5 % accuracy, CER 0.0193** overall (German 69.0 % / 0.0363, Russian 100 % / 0) against a 0.5 % identity floor; the map-lookup ceiling is 100 % by construction and labelled as such. Metrics follow Bollmann (2019, N19-1389) at token level. `npm run build-ortho-benchmark` rebuilds from sibling checkouts; `npm run score-ortho-benchmark` re-checks the committed baseline or scores an `id<TAB>prediction` TSV. Six tests pin counts, uniqueness, hash, split ratios, rule cases, baseline agreement and the rights/grounding caveats. Grounding is source-text-level, **not scan-image verified**; Russian is single-dictionary (KOW, 1854) — both stated in `data/ortho/normalization_benchmark.card.md` and on the `/tools/ortho-drift` page.
