## 🧠 Dev Notes & Hypotheses

- R2 promotion gate vs reproduction: "parser promotion" = changing the 5 packet decision rules (deferred). Reproducing the archived package with *existing* heuristics is NOT promotion and is the allowed no-human work.
- H1 key finding: `div` mode (PWG/PWK) over-counts in H1 because `<div>` tags are structural (multi-depth), not semantic sense boundaries. Semi-clause proxy gives 1.127 vs archived 1.161 (3% under). The "no temporal inflation" conclusion reproduces regardless.
- BEN Roman numerals `{@I.@}/{@II.@}` are POS-class markers in compound sub-sections, NOT main sense divisions. Don't add them to H1 count.
- H2H3 panel: SHS/YAT use inline `\b\d+\. ` markers (not in `R2_DICTS`); must use `stripMarkup()` (not `cleanText()` with 220-char truncation) before splitting. WIL→SHS overlap 0.906 ≈ 0.82 archived — near-verbatim copy confirmed.
- Per-entry H1 metric confounded by MW headword-splitting (286k entries → many short); `r2_h1_panel.json` fixed-lemma panel removes this. AP90→AP edge useful for testing revision-only (no inflation expected within same family).
