## 🧠 Dev Notes & Hypotheses (Bugs, ideas, context)

- L0 GQD (H1578): the stemma's agreement number is **0.1456 GQD = 85.4% of the
  documented-descent quartets**. Two traps for anyone extending it. (1) The gold
  is a TREE and dictionary descent is reticulate — the five documented edges
  marked `UNREPRESENTABLE` in `data/L0/gold/gold_stemma_warrants.csv` (incl.
  PWG→MW) cannot be scored at all, so the figure is a floor, not a ceiling.
  (2) Do **not** re-canonicalise on it: `A_jaccard_upgma` scores 0.1102, better
  than the pre-registered `B_whamming` canonical, and promoting it post hoc is
  the exact overfit pre-registration prevents.
- **`canonical_consensus.newick` is NOT a consensus tree** (found in H1578,
  filed as csl-atlas#313). `s3_cladogram.py`'s 1000× bootstrap loop only
  accumulates per-edge support; the canonical file is the single-run UPGMA on
  the full `B_whamming` matrix and is byte-identical to
  `B_whamming_upgma.newick`. Support numbers are fine; the prose that called it
  a consensus was corrected 26-07-2026. If anyone ever publishes a real
  majority-rule consensus, the L0 GQD numbers must be recomputed.
- `npm run regen-review-artifacts` must never pass R2 `--reseed`; it snapshots
  and byte-compares preserved human fields around regeneration.
- `npm run verify` intentionally requires a clean tracked tree before and after
  two regeneration passes. Run it after committing local release changes.
- The remaining audit result is a development-server-only low esbuild advisory;
  see `docs/DEPENDENCY_SECURITY.md`. Do not use forced dependency overrides.
- The timeline route is a measured performance target for v0.3.0, not a reason
  to mix redesign into the v0.2.0 release branch.
- Strict downloads require reviewer `gasyoun`, all items voted, and rejection
  notes in `corrected-label: rationale` form. Incomplete drafts remain local
  with `complete:false`; the atlas validator requires complete strict exports.
- The `v0.2.0` tag resolves exactly to `42d8187`; it has no DOI and no Zenodo
  connection. PR #267 and Pages run 29610351960 were green before tagging.
