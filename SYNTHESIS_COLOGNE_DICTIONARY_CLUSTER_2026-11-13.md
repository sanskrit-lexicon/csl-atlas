## Themes

1. **The cluster's defining method is pre-registration + a regeneration gate: the interpretation grid is committed before the run and the numbers must regenerate from committed rows, or the gate exits non-zero.** The whole PD/PWG/NWS/DCS programme runs off one hyperresearch protocol (`final_report_pwg-nws-pd-dcs-8294e5.md` §8/§12/§13) committed before Stage 1; the Stage-3 grid is sha-pinned in `tests/forensic/test_triangulation_stage3.py` so "any post-hoc edit to this grid fails the drift gate" ([grid_preregistration.md:10-14](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/triangulation_stage3/grid_preregistration.md)); every Stage report closes with `*_check.py` → exit 0 over committed row-level TSVs ([PWG_DCS_JOIN_STAGE1:28-30](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PWG_DCS_JOIN_STAGE1_2026-10-30.md), [NWS_LAYER_STAGE2:47-49](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/NWS_LAYER_STAGE2_2026-10-30.md)). Two gates were re-run live at this pass and both are green (Code spot-checks rows 1–2). The same discipline surfaces as negative enforcement: the retracted 82.7 figure is **structurally barred** from published numbers by a guard in `nws_layer_check.py` — the retraction is code, not prose.
2. **Apparatus-type asymmetry is the diagnostic engine, and it decided the cluster's biggest fork.** Three apparatus types are pre-typed (PD = primary/partial/breadth-heavy late-20th-c; PWG = primary/complete/1855–75 edition-anchored; NWS = secondary meta) and the grid rule is: convergence across types → corpus-structural; divergence along type lines → measures the editorial artefact; contradiction → localizes to one programme ([grid_preregistration.md:24-31](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/triangulation_stage3/grid_preregistration.md)). Five of six branches fired; BR1 overturned A68's "three-quarters of citation practice outside DCS" as a **class** claim — PWG points into DCS at 63.53 % (46.62–76.08 bootstrap) vs PD's 25.16 % band 19.15–31.52 — and BR2 showed two *primary* apparatuses differing by 38.43 pp on the shared frontier, so "programme, not apparatus type, is the explanatory axis" ([TRIANGULATION_STAGE3:16-37](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/TRIANGULATION_STAGE3_2026-10-30.md)). BR3's non-firing is the sharpest aside: PWG_α ≈ PWG_Ω to 0.06 pp refutes the alphabetical-scope artefact at the level dimension — "PD's programme did [distort], letter-a anchoring did not" ([TRIANGULATION_STAGE3:102-105](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/TRIANGULATION_STAGE3_2026-10-30.md)). BR4: NWS holds PWG's inventory (82.57 % containment) but not its attestation allocation (ρ = 0.3414; literature refs ρ = 0.0085) — a secondary apparatus reproduces *what* its parent inventory holds, not *where* primary mass sits ([NWS_LAYER_STAGE2:74-88](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/NWS_LAYER_STAGE2_2026-10-30.md)).
3. **Denominators are objects, not estimates — this cluster's counter-move to canonical-figure drift is a ledger of bases with a refusing checker.** "No percentage without its base in the same sentence or row" is now a written rule ([PD_DCS_CORPUS_COVERAGE:964-967](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_DCS_CORPUS_COVERAGE_2026.md)): the same 118 covered works divide by ten different bases (7.99 % at 1,476, 8.21 % at 1,437, 5.81 % at the 2,031-row Index, and 10.55 % at 1,118 explicitly "a floor, never a denominator"), and `pd_canon_ledger.py --check` refuses to write if a computed percentage disagrees with its JSON ([PD_DCS_CORPUS_COVERAGE:935-940](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_DCS_CORPUS_COVERAGE_2026.md)). The same defect class is caught twice more: pages-vs-entries mixing in one ratio (H6985, cited [DICTIONARY_PLAN_DEVIATION:17-19](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/DICTIONARY_PLAN_DEVIATION_2026-10-18.md)), and the "~3× plan-deviation" rule splitting into two families — size overshoots 2.50× median, schedule 8.90× median, "reporting one number for both is the same category error" ([DICTIONARY_PLAN_DEVIATION:14-19](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/DICTIONARY_PLAN_DEVIATION_2026-10-18.md)). W2's theme 2 (build-stamp discipline, blocked rule) meets its working sibling here: where SanskritLexicography's METHODS §2.8 rule is *impossible to follow* (kosha.db name collision), csl-atlas's canon rule is enforced by a checker that fails closed.
4. **The C1→C2→C3 ladder keeps availability, edition identity and scan targets as three separate measures and refuses silent promotion.** C1: 45.11 % of PD's 419,890 attestations sit on a positively verified machine-readable text — but the AOB-**exact** edition figure is 5.52 %, "the warning against using the 45.11 % headline as an edition-alignment claim" ([PD_EDITION_AVAILABILITY_C1:5-50](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_EDITION_AVAILABILITY_C1_2026-10-29.md)). C2: 97.72 % of entries carry a well-formed `(siglum, locus)` pair (391,444 pairs) with **every** H6949 marker reconciled into a named diagnostic class — "not silently dropped" ([PD_LOCUS_FIELDS_C2:7-57](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_LOCUS_FIELDS_C2_2026-10-29.md)). C3: work identity 99.57 % vs AOB edition identity 50.25 % vs AOB-exact scan targets 0.86 % of Index rows (24.00 % locus-level) — "work-level availability is never silently promoted to edition identity" ([PD_AOB_SCAN_LINKS_C3:5-34](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_AOB_SCAN_LINKS_C3_2026-10-30.md)). Each rung's status string is part of the contract: "bounded, reproducible **lower-bound** measurement… no human `reviewed` claim" — the 54.89 % unresolved remainder is "unresolved, not evidence of absence" ([PD_EDITION_AVAILABILITY_C1:3-9](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_EDITION_AVAILABILITY_C1_2026-10-29.md)).
5. **Declared-vs-exercised is the cluster's portable meta-finding.** NWS declares 174 works and exercises 82 (47.13 %) — recomputed only from the dated scrape, never filename stems ([NWS_LAYER_STAGE2:38-45](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/NWS_LAYER_STAGE2_2026-10-30.md)); PD's declared canon (≈1,476 AOB rows) and its exercised letter-a set (~2,445) are different objects (§9 ledger); Cologne's digital PD is **stale by 11 volumes / 1,728 pages / 11 years** against the print record while KoshaSHRI's metadata is current through 2019 ([PD_KOSHASHRI_STALENESS_AUDIT:5-11](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_KOSHASHRI_STALENESS_AUDIT_2026.md)); and on the plan side only 6 of 17 league-table dictionaries document a numeric plan at all — "not one of the seven finished Sanskrit dictionaries has a documented numeric plan" ([DICTIONARY_PLAN_DEVIATION:59-89](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/DICTIONARY_PLAN_DEVIATION_2026-10-18.md)). Stage 3 names the distinction's provenance: A68's declared-canon 8.0 % "rests on" it and NWS's 82/174 corroborates it ([TRIANGULATION_STAGE3:113-114](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/TRIANGULATION_STAGE3_2026-10-30.md)).
6. **The MW-vs-PWG missing-entries scan replaces "MW error" guessing with an evidence-class split and a pinned trap canary.** Of 157,994 distinct base headwords, 25,710 lack a verbatim MW resolution: **19,465 class (a) missing-by-error** (PWG/pwk cite the word) vs **6,245 class (b) expected absence** (never cited — derivatives), with the (a)/(b) split "arbitrates only by citation evidence, not by MW's editorial policy" ([MW_VS_PW_MISSING_ENTRIES_SCAN:22-28](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/MW_VS_PW_MISSING_ENTRIES_SCAN_2026-10-31.md), [caveat 1:123-126](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/MW_VS_PW_MISSING_ENTRIES_SCAN_2026-10-31.md)). The `kAritra~kArita` 0.92 near-form trap — a *different* word (abstract vs causative participle) — is pinned as the canary of the review-flag tier: "a review flag, not proof of presence" ([MW_VS_PW_MISSING_ENTRIES_SCAN:61-63](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/MW_VS_PW_MISSING_ENTRIES_SCAN_2026-10-31.md), [112-116](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/MW_VS_PW_MISSING_ENTRIES_SCAN_2026-10-31.md)). The strongest worklist is 897 `mw_lacks` candidates corroborated by ≥2 of 39 independent Cologne dictionaries. The same spirit — external question, evidence-keyed answer, no direct posting — governs the drafted reply for csl-corrections #119.
7. **A siglum apparatus is an identity problem before it is a coverage problem.** The PD shared work registry's identity rule is explicitly "no guessing": folded printed siglum **plus** folded Devanagari title, exact-fold joins only, and "siglum equality alone is refused: PWG prints `MAHĀBH.` for the epic while PD prints `MahāBh.` for the Mahābhāṣya — the folds collide, the references do not" ([PD_SHARED_WORK_REGISTRY:27-45](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_SHARED_WORK_REGISTRY_2026.md)). 418 registry rows stay unresolved and 57 cross-dictionary siglum folds name >1 work (55 resolved, 2 partial). The same typed-graph view W2 found in PWG's `<ls>` apparatus (witnesses vs authorities) is here measured at canon level: the ABBREV census re-founds Gasūns 2006's hand tables as computed polysemy over 45 dictionaries / 1,506,391 entries / 34,765 distinct labels ([ABBREV_CENSUS_V1:12-26](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/ABBREV_CENSUS_V1_2026.md)), and Stage 3's per-stratum table makes the mediation channel numeric — second-hand mass (Bhāgavatapurāṇa "nach Anführungen im VP. und ŚKDR.") is "reported, never pooled into the headline" ([PWG_DCS_JOIN_STAGE1:81-90](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PWG_DCS_JOIN_STAGE1_2026-10-30.md)).

## Agreements

1. **Pre-register the grid/thresholds, then never retune** — the Stage-3 grid, the H5/H6 operationalizations ("declared before the join ran on the measured rows, mirrored in the gate", [NWS_LAYER_STAGE2:117-118](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/NWS_LAYER_STAGE2_2026-10-30.md)) and the work-bootstrap bands all follow W2's CONTRADICTIONS discipline (claims tested against frozen thresholds). The retraction guard is even implemented as a numeric check (`abs(x − 82.7) < 1e-9` → fail).
2. **Separate axes before comparing** — pages vs entries (H6985), size vs schedule (2.50× vs 8.90×), work-level vs edition-level vs scan-level availability (45.11 % vs 5.52 % vs 0.86 %), pooled vs stratum-excluded coverage (59.00 % vs 63.53 %), raw vs folded sigla (3,186 vs 2,409). Every headline in the cluster carries its axis in the same row.
3. **Honest null and explicit residue over smoothing** — "unresolved, not evidence of absence" (C1); "the honest unknown is Pune's entry schema" (`UNKNOWN_NOT_PUBLICLY_OBSERVABLE`, [PD_KOSHASHRI_STALENESS_AUDIT:29-34](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/PD_KOSHASHRI_STALENESS_AUDIT_2026.md)); "record the pending state rather than manufacturing a survival in an independent tradition" (Stage 4 kill-exit, [STAGE4:75-78](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/STAGE4_EXTERNAL_PORTABILITY_2026-10-30.md)); STOP_NO_PRINT_ACCESS over a positive fidelity claim.
4. **Regeneration from committed rows is the acceptance evidence** — every report's numbers live in a committed JSON/TSV with a `*_check.py` gate and `tests/forensic` pins; W2's equivalent is the pwg_ru store's reproducibility stamps. This pass re-derived 6 headline numbers from the JSONs and re-ran 2 gates (spot-checks).
5. **Reuse-not-rebuild with pin-refusal** — the MW scan's builder "refuses to run if pwg.txt drifts off the Stage-1 pin" and pins the same 123,366 entry register ([MW_VS_PW_MISSING_ENTRIES_SCAN:65-77](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/MW_VS_PW_MISSING_ENTRIES_SCAN_2026-10-31.md)); the C2 extractor "reuse[s] H6949's traversal" ([CLAUDE.md:109-115](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/CLAUDE.md)); the atlas "may cite outputs, never rebuild ingestion" ([ATLAS_RESEARCH_AGENDA:557-561](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/docs/ATLAS_RESEARCH_AGENDA.md)).
6. **External questions enter as keyed worklists, not verdicts** — KnbRao's #119 question ends as a two-class candidate set with per-row evidence keys and a drafted reply "for MG's review (no direct posting)"; Stage 4's Russian analogue upgrades to "verified structural analogue" but "executability of a run is successor work (pre-registration first)" ([STAGE4:48-53](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/STAGE4_EXTERNAL_PORTABILITY_2026-10-30.md)).
7. **Date and hash every "current state" claim** — the Stage-4 census's value "is exactly that it is boring: catalog rot and moving denominators are §11 threats, so… no 'current state' claim rests on an undated row" ([STAGE4:80-87](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/reports/STAGE4_EXTERNAL_PORTABILITY_2026-10-30.md)); the NWS attestation is recomputed "only from the dated scrape (fetched 2026-10-06, html sha `86c9495e…`, hash-pinned in three places)".
