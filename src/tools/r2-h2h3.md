<h2>Robustness — confound controls &amp; threshold sensitivity</h2>
<p class="note">The H2 chart above is the <b>unadjusted</b> gap. Senses cluster within lemmas (shared fate) and citation is entangled with sense prominence, so the naive two-proportion test (z = 3.0, p ≈ 0.002) overstates the evidence. Refitting <code>survived ~ cited + position + glossLen + crossDict</code> (centrality controls) <code>+ edge fixed effects</code> with lemma-cluster-robust SEs attenuates the citation effect to <b>OR ≈ 1.75, p = 0.16 — not significant</b> (<code>h2Controlled</code> in <code>data/lexico/r2_h2h3.json</code>). The 17-point gap is real but is largely centrality + edge baseline, not a clean citation effect.</p>
<p class="note"><b>Threshold sensitivity (referee item M4).</b> Survival is defined as gloss-word Jaccard ≥ 0.15 — a researcher choice.
