# Data-richness typology (L0-L10)

Every locally-present CDSL dictionary placed on the roadmap's explicit
**L0-L10 data-richness ordinal scale** — scan-only to full structured semantic
web — with a machine-readable justification per level: which criterion
matched, and from which committed source. See
[`docs/METALEXICOGRAPHY_ROADMAP.md`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/docs/METALEXICOGRAPHY_ROADMAP.md)
§1 for the typology and §8 Phase M1 for this deliverable.

## Per-level criteria for one dictionary

```js
const pick = view(Inputs.select(data.rows.map(r => r.code), { label: "Dictionary", value: "MW" }));
```

```js
const picked = data.rows.find(r => r.code === pick);
const criteriaRows = Object.values(picked.criteria).map(c => ({
  level: c.level,
  name: data.levels.find(l => l.level === c.level)?.name ?? "",
  met: c.met ? "✓" : "—",
  evidence: c.evidence
}));
display(Inputs.table(criteriaRows, {
  columns: ["level", "name", "met", "evidence"],
  header: { level: "L", name: "Name", met: "Met", evidence: "Evidence" },
  width: { evidence: 520 },
  rows: 11
}));
```

```js
display(csvDownloadButton(criteriaRows, `richness-typology-${pick}.csv`));
```
