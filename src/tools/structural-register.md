# Structural Register Scatter

H6 asks whether citation style plus grammar marking predicts dictionary family.
This page is dictionary-first: it uses generated dictionary structure data only,
not corpus frequency, standards exports, or GitHub activity.

```js
const data = FileAttachment("../data/dicts/structural-register.json").json();
```

```js
import * as Plot from "npm:@observablehq/plot";
```

```js
const rows = data.rows;
const familyOrder = ["western-tagged", "indigenous-prose", "index-catalogue", "reverse-bilingual", "specialized", "unknown"];
const modeOrder = ["tagged", "iti", "mixed", "low"];
const familyColors = new Map([
  ["western-tagged", "#1f77b4"],
  ["indigenous-prose", "#2ca02c"],
  ["index-catalogue", "#9467bd"],
  ["reverse-bilingual", "#ff7f0e"],
  ["specialized", "#7f7f7f"],
  ["unknown", "#bcbd22"]
]);
const modeSymbols = new Map([
  ["tagged", "circle"],
  ["iti", "triangle"],
  ["mixed", "diamond"],
  ["low", "cross"]
]);
```

## Citation Register x Grammar Marking

```js
display(Plot.plot({
  width: Math.min(width, 980),
  height: 560,
  marginLeft: 72,
  marginBottom: 64,
  grid: true,
  x: {label: "citation-register share (% entries)", domain: [0, 100]},
  y: {label: "grammar-marking share (% entries)", domain: [0, 100]},
  color: {
    legend: true,
    domain: familyOrder,
    range: familyOrder.map(f => familyColors.get(f))
  },
  symbol: {
    legend: true,
    domain: modeOrder,
    range: modeOrder.map(m => modeSymbols.get(m))
  },
  marks: [
    Plot.frame(),
    Plot.dot(rows, {
      x: "citationRegisterPct",
      y: "grammarPct",
      fill: "familyLabel",
      stroke: "white",
      strokeWidth: 1,
      r: d => Math.max(4, Math.min(17, Math.sqrt(d.records) / 35)),
      symbol: "citationRegisterMode",
      tip: {
        format: {
          citationRegisterPct: d => `${d.toFixed(2)}%`,
          grammarPct: d => `${d.toFixed(2)}%`,
          taggedCitationPct: d => `${d.toFixed(2)}%`,
          inlineItiPct: d => `${d.toFixed(2)}%`,
          records: d => d.toLocaleString()
        }
      }
    }),
    Plot.text(rows.filter(d => ["MW", "PWG", "PWK", "AP", "SKD", "VCP", "KRM", "BHS", "ACC"].includes(d.code)), {
      x: "citationRegisterPct",
      y: "grammarPct",
      text: "code",
      dy: -12,
      fontSize: 11,
      fill: "currentColor"
    })
  ]
}));
```

The x-axis uses `max(taggedCitationPct, inlineItiPct)`, so indigenous `iti`
evidence is visible instead of being treated as zero `<ls>` evidence. Tooltips
retain both raw components.

## Citation Mode By Family

```js
const modeFamily = familyOrder.flatMap(family =>
  modeOrder.map(mode => ({
    family,
    mode,
    count: rows.filter(d => d.familyLabel === family && d.citationRegisterMode === mode).length
  }))
).filter(d => d.count > 0);

display(Plot.plot({
  width: Math.min(width, 880),
  height: 320,
  marginLeft: 132,
  x: {label: "dictionaries", grid: true},
  y: {label: null, domain: familyOrder},
  color: {legend: true, domain: modeOrder, range: ["#1f77b4", "#2ca02c", "#9467bd", "#7f7f7f"]},
  marks: [
    Plot.barX(modeFamily, {x: "count", y: "family", fill: "mode"}),
    Plot.text(modeFamily, {x: "count", y: "family", text: d => d.count, dx: 7, fontSize: 11}),
    Plot.ruleX([0])
  ]
}));
```

## How To Read It

- A cluster is evidence for structural similarity, not direct proof of descent.
- A zero can be a convention gap. It does not automatically mean the dictionary
  lacks the feature.
- `iti` and `<ls>` are different citation registers and should remain visible.
- H4 semantic fields live on `/tools/semantic-fields`; this chart should not
  mix topical vocabulary into the H6 structural-register claim.
