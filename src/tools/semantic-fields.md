# Semantic Fields

H4 asks whether dictionaries show measurable topical coverage profiles when
their headword sets are projected onto the Amarakosa's native varga taxonomy.
This page is dictionary-first: it uses generated dictionary headword evidence
only, not corpus frequency, standards exports, or GitHub activity.

```js
const data = FileAttachment("../data/dicts/semantic-fields.json").json();
```

```js
import * as Plot from "npm:@observablehq/plot";
```

```js
const fields = data.fields.slice().sort((a, b) => a.fieldOrder - b.fieldOrder);
const dictRows = data.dictionaries;
const coreCodes = new Set(data.coreDicts);
const coreCoverage = data.coverage
  .filter(d => coreCodes.has(d.code))
  .map(d => ({...d, dictLabel: dictLabel(d.code)}));

const familyOrder = data.familyLabels;
const familyColors = new Map([
  ["western-tagged", "#2f6f9f"],
  ["indigenous-prose", "#2f7d4f"],
  ["index-catalogue", "#8a5a9e"],
  ["reverse-bilingual", "#b86b2b"],
  ["specialized", "#6f6f6f"],
  ["unknown", "#9a8f2a"]
]);

function dictLabel(code) {
  return data.dictionaries.find(d => d.code === code)?.label ?? code.toUpperCase();
}

function pct(value, digits = 1) {
  return `${(value * 100).toFixed(digits)}%`;
}
```


The matrix is a headword-coverage view. A low cell can mean the dictionary uses
prose, citation, or inflected conventions that do not expose every AMAR synonym
as a comparable `<k1>` headword.

## How To Read It

- The fields are AMAR vargas, not a modern semantic ontology.
- Coverage means normalized AMAR synonyms found as dictionary `<k1>` headwords.
- SKD/VCP-style prose and citation conventions can produce false lows.
- The chart supports H4 as a measurable bias layer, not as a final claim about
  semantic exhaustiveness.
