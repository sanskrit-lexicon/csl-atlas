# Cross-Reference Lineage

M6 asks whether dictionary-internal cross-reference graphs preserve lineage
signals. The answer is deliberately not binary: AP and AP90 behave like the
same dictionary across editions, while MW and PWG share a real cross-reference
core without wholesale graph inheritance.

```js
const data = FileAttachment("../data/dicts/xref-lineage.json").json();
```

```js
import * as Plot from "npm:@observablehq/plot";
```

```js
const pairs = data.pairs;
const readablePairs = pairs.filter(d => d.sharedSources > 2);
const readingOrder = ["positive-control", "headline-shared-core", "comparison", "too-few-shared-sources"];
const readingColors = new Map([
  ["positive-control", "#2f7d4f"],
  ["headline-shared-core", "#2f6f9f"],
  ["comparison", "#8a5a9e"],
  ["too-few-shared-sources", "#6f6f6f"]

function pct(value, digits = 1) {
  return `${(value * 100).toFixed(digits)}%`;
}
```

## Inheritance-Rate Ceiling

```js
const rateRows = readablePairs.flatMap(d => [
  {...d, side: d.aLabel, rate: d.aInheritanceRate},
  {...d, side: d.bLabel, rate: d.bInheritanceRate}
]);

display(Plot.plot({
  width: Math.min(width, 920),
  height: 360,
  marginLeft: 88,
  marginRight: 24,
  grid: true,
  x: {label: "matched edges on each side (%)", domain: [0, 1], tickFormat: d => `${d * 100}%`},
  y: {label: null, domain: readablePairs.map(d => d.label)},
  color: {legend: true},
  marks: [
    Plot.barX(rateRows, {
      x: "rate",
      y: "label",
      fill: "side",
      tip: {format: {rate: pct, sharedSources: d => d.toLocaleString()}}
    }),
    Plot.ruleX([0])
  ]
}));
```

AP x AP90 is the positive control: the same Apte dictionary across editions
keeps about 85% of its comparable cross-reference edges. MW x PWG is much lower
on both sides, so the finding is a shared core, not wholesale inheritance.

## How To Read It

- The comparison is restricted to lemmas both dictionaries cross-reference.
- A high AP/AP90 rate is a positive control for edition-level continuity.
- MW/PWG overlap is real but partial; most cross-reference expansion remains
  independent.
- Tiny shared-source pairs are shown in the table but should not drive lineage
  claims.
