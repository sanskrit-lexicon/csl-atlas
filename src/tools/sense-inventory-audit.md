# Cross-dictionary sense-inventory audit

This page upgrades the [entry-count divergence](/tools/sense-divergence) proxy to a **sense-unit comparison**. It asks how many sense sections MW, AP, PWG and PWK devote to the same lemma, how often those counts disagree, and how well two independent automated keys agree. It is an inventory audit, **not** a word-sense-disambiguation model and **not** a curated semantic sense inventory.

## Trust Block

- Evidence: `data/sense/inventory_audit.json`, `data/sense/inventory_audit.csv`, `data/sense/inventory_audit_sample.tsv`, and `data/sense/inventory_audit.source.json` (input hashes, command, live-source record counts), generated by `scripts/build-sense-inventory-audit.mjs`.
- Metric: sense units = validated per-dictionary section/marker counts; disagreement = core dictionaries do not all report the same count for a lemma. These are **structural** units, not semantic meanings.
- Sample: 500 lemmas — 200 disparity-enriched lemmas from the committed `sense-depth` gaps plus 300 deterministic SHA-256 lemmas stratified by how many core dictionaries contain them.
- Validation: `npm run build-sense-inventory-audit` regenerates; `node --test test/sense-inventory-audit.test.mjs` checks the pins below; checked by `npm run build`.
- Limitations: WIL, VCP and SKD have no validated sense adapter, so they contribute entry coverage but not sense units. No ELEXIS MWSA inventory is available locally, so external MWSA evaluation is an honest null. The kappa is automated coding agreement between two segmenters on MW, not human inter-annotator agreement. The human blind double-key and adjudication required for full acceptance could not be run unattended; `audit.humanGold.status` is `blocked` and the TSV records `unadjudicated-automated`.
- Owner repo: `csl-atlas`.
- Next use: open the source record for a high-spread lemma before citing a cross-dictionary sense difference; treat the count as a review signal.

## Cross-dictionary survival

Share of lemmas found in row dictionary `from` that are also found in column dictionary `to` (within the disparity stratum).

```js
const core = audit.coreSenseDicts;
const survivalLookup = new Map(audit.crossDictSurvival.map(r => [`${r.from}:${r.to}`, r]));
display(Inputs.table(core.map(from => {
  const row = { from: from.toUpperCase() };
  for (const to of core) {
    if (from === to) { row[to.toUpperCase()] = "—"; continue; }
    const r = survivalLookup.get(`${from}:${to}`);
    row[to.toUpperCase()] = r ? `${(r.rate * 100).toFixed(1)}%` : "—";
  }
  return row;
}), { columns: ["from", ...core.map(c => c.toUpperCase())] }));
```

## MWSA relations and external inventories

The ELEXIS MWSA vocabulary is `=`, `superset`, `subset`, `related`. Internal R2 anchor alignments expose Jaccard scores and shared anchors, so only `=` and `related` are measurable here. Superset/subset require full sense sets from an MWSA inventory, which is not present in this workspace.

```js
const mws = audit.mwsRelationAlignment;
display(Inputs.table([
  { relation: "=", rows: mws.measured["="], status: "measured on internal R2 anchors" },
  { relation: "related", rows: mws.measured.related, status: "measured on internal R2 anchors" },
  { relation: "unrelated", rows: mws.measured.unrelated, status: "measured on internal R2 anchors" },
  { relation: "superset", rows: "—", status: "not measurable without MWSA sense sets" },
  { relation: "subset", rows: "—", status: "not measurable without MWSA sense sets" }
```

## Sample table

```js
const strat = view(Inputs.select(["all", "disparity", "coverage"], { label: "Stratum", value: "all" }));
const minSenses = view(Inputs.range([1, 50], { label: "Min MW sense units", step: 1, value: 1 }));
```

```js
const filtered = audit.rows.filter(r => {
  if (strat !== "all" && r.stratum !== strat) return false;
  const mw = r.senseUnits?.mw?.units ?? 1;
  return mw >= minSenses;
});
const displayRows = filtered.map(r => ({
  lemma: slp1ToIast(r.k1),
  key: r.k1,
  stratum: r.stratum,
  coreDicts: r.nCoreDicts,
  entries: Object.entries(r.coreEntryCounts).map(([k, v]) => `${k}:${v}`).join(" "),
  senses: Object.entries(r.senseUnits).map(([k, v]) => `${k}:${v.units}`).join(" "),
  mwAdapter: r.mwDoubleKey?.adapterUnits ?? "",
  mwGloss: r.mwDoubleKey?.boundaryUnits ?? "",
  agree: r.mwDoubleKey?.agreeMultiSense ?? "",
  source: r.mwDoubleKey?.href ?? ""
}));
display(html`<p style="color:var(--theme-foreground-muted);font-size:13px">
  Showing ${displayRows.length.toLocaleString()} of ${audit.rows.length.toLocaleString()} sampled lemmas.
</p>`);
display(Inputs.table(displayRows, {
  columns: ["lemma", "stratum", "coreDicts", "entries", "senses", "mwAdapter", "mwGloss", "agree", "source"],
  format: {
    agree: x => x === true ? "yes" : x === false ? "no" : "",
    source: href => href ? html`<a href=${href} target="_blank" rel="noopener">source</a>` : ""
  },
  sort: "coreDicts",
  reverse: true,
  rows: 50
}));
```
