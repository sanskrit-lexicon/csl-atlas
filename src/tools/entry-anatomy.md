# Entry anatomy

A radar view of one headword's microstructure feature matrix, overlaid across
every dictionary that carries it — how much each dictionary leans on tagged
citations, inline `iti` citations, grammar, etymology, cross-references,
homonym marking, divisions, subentries, and root markers, plus raw entry size.
Pick an anchor lemma below; each dictionary is one overlaid series on the
radar.

## Trust Block

- Evidence: `data/lexico/micro-<lemma>.json` (one file per anchor lemma), generated from CDSL `csl-orig` source files.
- Limitations: feature counts are regex tallies over the raw entry body, not validated citation resolutions — see the warning below on the 10-feature scope.
- Validation: generated by `npm run build-micro-entry -- <lemma>`; checked by `npm test` and `npm run build`.
- Owner repo: `csl-atlas`.
- Next use: use the radar to pick a dictionary contrast (e.g. citation-dense vs. prose), then open the source excerpt before citing the pattern.

<div class="warning" label="Evidence: derived">
The generator (<code>scripts/build-micro-entry.mjs</code>) tallies <b>10</b>
structural features per entry (size, tagged/inline citations, grammar,
etymology, cross-reference, homonym, division, subentry, root). The research
roadmap's "24-dim profile" figure is aspirational for a future, richer
extraction pass — this page renders the 10 features actually implemented
today, not a silently-reduced 24.
</div>

```js
// Polar layout: n axes evenly spaced starting at 12 o'clock, one axis per
// feature key; each dictionary's row becomes a closed polygon, radius
// normalized 0-1 against the max value for that feature among the current
// lemma's dictionaries (so a radar is only ever compared within one lemma).
function radarGeometry(rows, featureKeys, radius = 180) {
  const n = featureKeys.length;
  const angleOf = i => -Math.PI / 2 + i * (2 * Math.PI / n);
  const maxByFeature = Object.fromEntries(
    featureKeys.map(key => [key, Math.max(1, ...rows.map(r => r[key] ?? 0))])
  );
  const axisPoints = featureKeys.map((key, i) => {
    const angle = angleOf(i);
    return { key, x: radius * Math.cos(angle), y: radius * Math.sin(angle) };
  });
  const seriesPoints = rows.flatMap(row =>
    featureKeys.map((key, i) => {
      const angle = angleOf(i);
      const value = row[key] ?? 0;
      const normalized = value / maxByFeature[key];
      return {
        dict: row.dictionary,
        feature: key,
        value,
        normalized,
        x: normalized * radius * Math.cos(angle),
        y: normalized * radius * Math.sin(angle)
      };
    })
  );
  const spokes = axisPoints.flatMap(p => [{ key: p.key, x: 0, y: 0 }, { key: p.key, x: p.x, y: p.y }]);
  const gridSteps = 48;
  const gridLevels = [0.25, 0.5, 0.75, 1].flatMap(level =>
    Array.from({ length: gridSteps + 1 }, (_, i) => {
      const angle = angleOf(0) + (i * (2 * Math.PI)) / gridSteps;
      return { level, x: level * radius * Math.cos(angle), y: level * radius * Math.sin(angle) };
    })
  );
  const labels = axisPoints.map(p => ({ key: p.key, x: p.x * 1.16, y: p.y * 1.16 }));
  return { axisPoints, seriesPoints, spokes, gridLevels, labels, maxByFeature };
}
```

## Radar — feature profile overlaid across dictionaries

```js
const geo = radarGeometry(payload.dictionaries, payload.featureKeys, 180);
const dictDomain = payload.dictionaries.map(r => r.dictionary);

display(Plot.plot({
  width: 760,
  height: 720,
  marginTop: 20,
  marginBottom: 20,
  x: { domain: [-240, 240], axis: null },
  y: { domain: [-240, 240], axis: null },
  color: { legend: true, label: "Dictionary", domain: dictDomain, scheme: "tableau10" },
  marks: [
    Plot.line(geo.gridLevels, { x: "x", y: "y", z: "level", stroke: "var(--theme-foreground-faint, #ccc)", strokeWidth: 1 }),
    Plot.line(geo.spokes, { x: "x", y: "y", z: "key", stroke: "var(--theme-foreground-faint, #ccc)", strokeWidth: 1 }),
    Plot.text(geo.labels, { x: "x", y: "y", text: d => FEATURE_LABELS[d.key], fontSize: 11 }),
    Plot.line(geo.seriesPoints, { x: "x", y: "y", z: "dict", stroke: "dict", curve: "linear-closed", strokeWidth: 2, opacity: 0.85 }),
    Plot.dot(geo.seriesPoints, {
      x: "x", y: "y", fill: "dict", r: 3, tip: true,
      title: d => `${d.dict} · ${FEATURE_LABELS[d.feature]}\n${d.value.toLocaleString()} (${(d.normalized * 100).toFixed(0)}% of max)`
    })
  ]
}));
```
