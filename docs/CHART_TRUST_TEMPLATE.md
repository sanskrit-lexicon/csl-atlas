# Chart Trust Template

Date: 2026-06-04

Status: required template for public atlas tools, charts, and use-case pages.
The short block is mandatory everywhere. The extended block is mandatory for
research charts and generated-data pages.

## Short Block

Use this on every public page:

```md
## Trust Block

- Evidence:
- Limitations:
- Validation:
- Owner repo:
```

Rules:

- Evidence names the dictionary records, generated files, or review reports that
  support the page.
- Limitations say what the page does not prove.
- Validation names the command, invariant, or manual check used.
- Owner repo must be exactly one repository: `csl-atlas`, `VisualDCS`,
  `csl-standards`, or `csl-observatory`.

## Extended Block

Use this on charts, research pages, and generated-data documentation:

```md
## Chart Trust Block

- Claim:
- Evidence label:
- Source files:
- Generated by:
- Validation:
- Known false positives:
- Known false negatives:
- Review status:
- Owner repo:
- External dependencies:
- Boundary note:
```

## Evidence Labels

Use the atlas labels from [`EVIDENCE_LABELS.md`](EVIDENCE_LABELS.md):

| Label | Use in a trust block |
|---|---|
| `observed` | The page points to material directly present in dictionary records. |
| `derived` | The page presents a deterministic count, join, normalization, or comparison. |
| `inferred` | The page presents a heuristic hypothesis or unreviewed classification. |
| `machine-reviewed` | The page passed deterministic checks but not human review. |
| `human-reviewed` | A reviewer confirmed or corrected the relevant value. |

## Boundary Examples

| Page kind | Owner repo | Boundary note |
|---|---|---|
| Dictionary chooser | `csl-atlas` | Uses dictionary metadata and caveats only. |
| Reader lookup | `csl-atlas` | Static dictionary lookup, no corpus passage search. |
| Corpus-facing dictionary summary | `VisualDCS` | Atlas may later consume a compact dictionary-facing summary. |
| TEI/OntoLex loss report | `csl-standards` | Standards/export work, not atlas implementation. |
| GitHub activity chart | `csl-observatory` | Org-process evidence, not dictionary evidence. |

## Review Queue Addendum

For review queues, add one sentence before procedure:

```md
This queue proves: ...
```

Do this before adding instructions for reviewer actions. The first question is
what the queue shows about dictionary evidence; the second question is how a
human corrects it.
