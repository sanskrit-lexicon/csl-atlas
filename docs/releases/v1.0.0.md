## What ships

v1.0.0 is the archival snapshot of the atlas data as committed on `main`,
reproducible from committed JSON plus the `csl-orig` v02 source dictionaries.
The release carries no new code; it freezes and cites what is already public.

### Nine curated narrative chapters

Comparative microstructural analysis of nine narrative Sanskrit-dictionary
chapters: **MW, PWG, PWK, AP, WIL, SKD, VCP, ARMH, ABCH** — with per-dictionary
and cross-dictionary variants of every Tier-1 figure.

### All-dictionary coverage layer

Source: [`data/dictionary-coverage.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/dictionary-coverage.json)

- 43 CDSL v02 source dictionaries (every local dictionary shipping a main source file)
- 1,495,459 records
- 384,384,849 bytes (~384 MB) of source text analysed
- 369,886,246 characters

### Headword census

Source: [`data/headwords.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/headwords.json)

- 44 dictionaries
- 1,495,422 `<L>` headword entries

### Citation apparatus

Source: [`data/obs/citation_registers.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/obs/citation_registers.json), [`data/citations/`](https://github.com/sanskrit-lexicon/csl-atlas/tree/main/data/citations)

- 44 dictionaries; 1,496,157 entries
- 1,517,609 `<ls>` citations, of which 1,013,996 (66.8%) carry a page/volume locator
- 113,113 inline-iti markers
- `<ls>` citation graph: 912 nodes, 1,701 edges

### Etymology oracle

Source: [`data/etymology-oracle.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/etymology-oracle.json)

- 10 dictionaries; 67,172 etymology rows; 64,896 headwords with an assigned root

### Forensic suite

Source: [`data/forensic/`](https://github.com/sanskrit-lexicon/csl-atlas/tree/main/data/forensic)

- F1–F8 forensic reports over the MBH/Harivamsa witnesses and citation pools
  (102 committed artifacts), pinned to one recorded `csl-orig` revision.

### Evidence discipline

Every public claim carries an explicit evidence label
(observed / derived / inferred / reviewed). Every dataset carries a
`generatedBy` / `sourceRoot` provenance envelope. No model-generated text is
committed as dictionary content.

## What does not ship

- Any raw `csl-orig` source text, private review export, or model snapshot.
- A DOI until the repository is connected to Zenodo and the release is
  published — that is the whole point of
  [`docs/ZENODO_FIRST_DOI_CHECKLIST.md`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/docs/ZENODO_FIRST_DOI_CHECKLIST.md).
- DOI identifiers inside [`CITATION.cff`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/CITATION.cff) / [`.zenodo.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/.zenodo.json): they are back-filled after minting (DOI back-fill unit).

## Metadata state at drafting

- [`CITATION.cff`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/CITATION.cff) validates against the Citation File Format 1.2.0 schema.
- [`.zenodo.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/.zenodo.json) validates against the official Zenodo legacy deposit metadata schema (`zenodo/zenodo` `deposits/records/legacyrecord.json`); the only tolerated deviation is the `version` key, which is a documented Zenodo deposit field missing from that upstream schema file.
- `publication_date` is intentionally absent from `.zenodo.json`: the GitHub–Zenodo integration stamps the actual release date at mint time, and a value in the file would override it.
- Creator names are consistent across both files; Gasūns' ORCID 0000-0003-4513-884X is present in both. Funderburk/Andhrabharati ORCIDs remain pending (see README "Pending author actions").
