# csl-atlas v0.2.0

Release date: 2026-07-17

## What ships

- One production acceptance command for tests, validators, deterministic review
  artifacts, build, audit, and clean-tree checks.
- Rebuilt R2, H5, H4, and xref review evidence with preserved human overlays.
- Node 20/npm 10 and Observable Framework 1.13.4 pinning, plus a documented
  low-severity development-server advisory.
- A single governing 2026–2027 roadmap and a compact active session journal.

## What does not ship

- A DOI: v1.0.0 remains gated on cleared review evidence, confirmed contributor
  metadata, and an explicit Zenodo connection.
- Any raw `csl-orig` source text, private review export, or model snapshot.

The release tag freezes this committed data snapshot.
