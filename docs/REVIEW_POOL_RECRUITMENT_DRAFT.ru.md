# Черновик объявления: набор 5–10 студентов-рецензентов (RU)

## 1. Что это за набор

Сеть samskrtam.ru приглашает 5–10 студентов на первую волну ручной проверки
словарных данных проекта [csl-atlas](https://github.com/sanskrit-lexicon/csl-atlas):
три «заблокированных» пакета, которые машина размечать не имеет права
(`reviewStatus: machine-reviewed` / `agent-reviewed` / `needs-source-check`) —
только человек. Каждую строку независимо размечают два рецензента
(двойная разметка), расхождения сводит координатор, согласие считается каппой.
Механика листов и отчёта готовится параллельно
([H5307](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5307-Opus_csl-atlas_review-pool-v1-double-keying-design_23.09.26.md),
[H5308](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5308-OxAlpha_csl-atlas_review-pool-packets-to-double-keyed-sheets_23.09.26.md),
[H5310](https://github.com/gasyoun/Uprava/blob/main/handoffs/H5310-Fable_csl-atlas_review-pool-student-guide-ru_23.09.26.md)) —
публиковать объявление до их готовности рано (см. раздел 5).

## 2. Текст объявления (черновик)

---

### Проверьте словарные данные — и посмотрите, как делается научная лексикография

Мы проверяем данные Кёльнского корпуса санскритских словарей и вышли на место,
где машина бессильна: несколько сотен строк, где нужно прочитать словарную
статью глазами и выбрать один ответ из короткого списка. Нужны 5–10 человек —
программировать не надо.

**Что делать.** Вы получаете пакет — 5–105 строк. В каждой строке: отрывок
словарной статьи (Petersburger Wörterbuch и другие словари корпуса) и вопрос
с готовыми вариантами ответа, например «одно это деление слова или склейка
нескольких словарных записей?». Выбираете вариант, оставляете короткий
комментарий, если что-то смутило. Всё в веб-листе, без XML и без терминала.
Каждую строку размечают два человека независимо, потом сравниваем ответы —
так рождается согласие аннотаторов, мера, без которой лексикографические
данные не считают проверенными.

**Сколько времени.** Считайте 1–2 минуты на строку. Отсюда по пакетам:

| Пакет | Строк | Время |
|---|---|---|
| R2 «ae-reverse-bands» | 5 | 5–10 мин |
| R2 «div-source-scope» | 10 | 10–20 мин |
| R2 «indigenous-iti-authority» | 10 | 10–20 мин |
| R2 «source-gap-controls» | 17 | 15–35 мин |
| R2 «marker-run-scope» | 28 | 30–55 мин |
| xref: общие рёбра MW/PWG | 50 | 50 мин – 1 ч 40 мин |
| H4: семантические поля | 105 | 1 ч 45 мин – 3 ч 30 мин |

Весь пул — 225 строк, но брать его целиком никому не нужно: начните с
маленького пакета на 5–10 минут и решите, берёте ли следующий. H4-пакет
можно вести частями.

**Чему вы научитесь.** Как устроена словарная статья настоящего большого
словаря изнутри — структура, отсылки на источники, места, где издания
расходятся. Как работает научная аннотация: фиксированный словарь меток,
независимая разметка, измерение согласия. И главное — увидите, откуда берутся
числа в открытых данных: каждая ваша строка с комментарием попадает в
проверяемый след решения.

**Как засчитывается вклад.** Каждый рецензент получает именное указание
вклада в открытых данных проекта (уточнённая формулировка — у координатора).
Для студентов курсов сети это засчитывается как учебная работа по
согласованию с вашим преподавателем.

**Как записаться.** Напишите [контакт — заполнить перед публикацией],
назовите пакет, который хотите взять. Первая волна — до 10 человек, дальше
по очереди.

## 3. Происхождение чисел (проверяемый след)

Размеры сняты с закоммиченных файлов пакетов 24-09-2026:

- R2, 5 пакетов / 70 строк:
  [`data/lexico/r2_review_packets.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/lexico/r2_review_packets.json)
  — `packets[].rows`: div-source-scope 10, marker-run-scope 28,
  ae-reverse-bands 5, indigenous-iti-authority 10, source-gap-controls 17.
- H4, `sampleRows` = 105:
  [`data/lexico/h4_semantic_field_review_packet.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/lexico/h4_semantic_field_review_packet.json).
- xref, 40 shared-core + 10 prefix-control = 50:
  [`data/lexico/xref_source_check_packet.json`](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/data/lexico/xref_source_check_packet.json).

Формула времени: **строки × 1–2 мин** (прочитать контекст статьи, выбрать
метку из словаря, оставить комментарий). Диапазон честный: первая строка
пакета всегда медленнее последней. Итого пул: 225 строк × 2 независимых
прохода = 450 проходов; на 5 рецензентов — ~90 проходов на человека, на
10 — ~45.

Отличие от формулировки в H5307/H5308 («R2 ×10»): 10 — это только флагманский
пакет div-source-scope; полный R2-пул — 70 строк в 5 пакетах. Объявление выше
считает по полному пулу.

## 4. Зачёт вклада — варианты и вилка решения

Формулировка в тексте объявления (раздел 2) — рабочая. Жёсткое правило из
архива ([H2545](https://github.com/gasyoun/Uprava/blob/main/handoffs/archive/H2545-Sonnet_Uprava_student-annotator-irr-pipeline-tier0-to-research_10.08.26.md)):
условия зачёта утверждает человек **до** рекрутинга; неоплаченная
исследовательская работа, поданная как учебная без названного вклада, в этом
хозяйстве недопустима. Варианты на выбор:

1. Именная благодарность + указание вклада в README датасета (минимум,
   действует всегда).
2. Учебный зачёт по согласованию с преподавателем курса (нужна договорённость
   с конкретным курсом сети).
3. Соавторство/acknowledgment в отчёте по волне, если вклад превысил порог
   (порог назвать до публикации).
