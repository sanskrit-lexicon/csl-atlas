Monthly human-style review of the prefix-clustered `<ls>` siglum families generated by

Adjudicated by **Fable 5 (`claude-fable-5`)** in the MWS July planning session (S1), 02-07-2026.
Machine-readable verdicts: [dict-source-aliases.json](https://github.com/sanskrit-lexicon/csl-atlas/blob/main/src/data/dicts/dict-source-aliases.json).

## Method

- **Scope:** families 1–50 by total citation weight (CSV rows `bhag` … `kull`; ≈2/3 of all
  family-clustered citation mass).
- **Verdicts:** `merge` (alias→canonical recorded) / `keep-separate` (identity recorded) /
  `uncertain` (blocked on per-dict raw-form evidence — merging is forbidden until resolved).
- **Canonical key rule:** the fold of the standard modern siglum (usually the MW list form)
  when present, else the highest-frequency member.
- **Locator-suffix members** (`raghiii`, `dhatupxxxii`, `mbhi`, `paniv`, `susri` …) are NOT
  aliases but parsing artifacts: `baseForm`/`foldSiglum` must strip trailing roman-numeral
  tokens. That single fold fix removes ~120 pseudo-members and empties several families
  (`susr`, `aitb`, `dhat`, `pani`, `panv`, `mbhi`, `laty`, `mrcc`, `inds`, `nais`, `naig`, `gobh`)
  — implementation is Sonnet work, spec'd in
  [MWS planning SPEC-4](https://github.com/sanskrit-lexicon/MWS/blob/master/planning/specs/2026-07/SPEC-4-siglum-apply.md).
- Evidence consulted: live `csl-orig/v02` `<ls>` contexts, the MW authority file
  [mwauthorities_init.txt](https://github.com/sanskrit-lexicon/MWS/blob/master/mwauthorities/mwauthorities_init.txt),
  and the printed abbreviation conventions of MW/PW/PWK/AP90.

## MW source-layer rulings (start on the "unknown" queue)

Measured basis (02-07-2026, live `mw.txt`): 1,045 distinct base sigla, 855 unmapped before
this batch, but only **6.5% of citation instances** fall outside the v1.1.0 map — the
unknown queue is a long tail. This batch rules the head of that tail:

- **57 new layer assignments** (11 vedic, 18 classical, 6 puranic, 24 technical, 4 lexicographic)
  — see the v1.2.0 `map` diff. Non-obvious calls, each recorded as a decisionRule:
  MW self-references `IW`/`RTL`/`MWB` + the journal `IndSt` → **editorialReferences**
  (his own English books are not Sanskrit witnesses); genre labels `Buddh.`/`Jain.` →
  **unknown by design** (corpus labels, not works); Pañcarātra/Tantrasāra/Kālacakra/HYog →
  **technical** (new āgama/tantra rule); `Dharmaś.` → **classical** = Dharmaśarmābhyudaya
  (kāvya word-gloss contexts + the separate `Dharmas.`+section-number = Dharmasaṃgraha
  pattern, both with existing authority records — see
  [MWS#217](https://github.com/sanskrit-lexicon/MWS/issues/217) adjudication).
- **Left unknown deliberately:** commentators (`Sāy.`, `Kull.`, `Nīlak.`, `Mahīdh.`, `Śīl.`,
  `Madhus.`, `Śaṃkar.`, `Bādar., Sch.`) per the existing rule; fragments (`A`, `T`, `Kār.`,
  `Gmn.`, `Ml.`); ambiguous `Kāty.`, `Śāk.`, `Nār.` was ruled technical (Nārada-smṛti, per
  MW authority record `nAr` "Nārada's Law-book").
