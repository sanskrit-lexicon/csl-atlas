# Microstructure Plan Moved To Boundary-Safe Scope

Date: 2026-06-04

microstructure, publication scheduling, corpus-based dictionary planning,
standards tracking, and career planning. It is preserved as:

- `docs/archive/MICROSTRUCTURE_AND_CAREER_PLAN_LEGACY_CROSS_REPO_PROGRAM.md`

- verbal and nominal entry structure;
- subentry patterns;
- source-citation behavior;
- homonym and sense structure;
- dictionary-family comparison;
- reviewable evidence generated from dictionary entries.

Use these active atlas docs instead:

- `docs/MICROSTRUCTURE-MACROSTRUCTURE.md`

- `docs/LEXICOGRAPHY_ROADMAP.md`

DCS/corpus work, GitHub/org metrics, and trend tracking belong outside
`csl-atlas` unless rewritten as dictionary-evidence notes.
