# Article 1 Methods Moved To Legacy

Date: 2026-06-04

The former `article_1_methods.md` was an integrated cross-repo draft combining
GitHub/org observatory metrics, dictionary-structure evidence, publication
planning, and external usage ideas. It is preserved as:

- `docs/articles/article_1_methods_LEGACY_CROSS_REPO_METHODS.md`

That legacy file is not active implementation guidance.

Current ownership:

- Dictionary inheritance, convention fingerprints, microstructure,
  macrostructure, source-citation evidence, and sense-structure evidence belong
  in `csl-atlas`.
- GitHub/org metrics belong in `csl-observatory`.
- TEI/OntoLex/FrAC standards work belongs in `csl-standards`.
- DCS/corpus and grammar evidence belong in VisualDCS or a future grammar repo.

For active atlas methods, use the dictionary-specific docs:

- `docs/LEXICOGRAPHY_ROADMAP.md`
- `docs/RESEARCH_LAYER_ROADMAP.md`
- `docs/METALEXICOGRAPHY_ROADMAP.md`
- `docs/L0_HANDOFF.md`
- `docs/R2_FINDINGS.md`
