# csl-atlas — dictionary evidence context

Atlas over the Cologne Sanskrit Lexicon dictionaries: lineage, conventions, and review
gates. This glossary covers the authority/origin language used when weighing dictionary
evidence (ADR-0001).

## Language

**Grundlagen**:
The ultimate lexicographic sources of Sanskrit dictionary-making: PWG (Böhtlingk & Roth)
and PW (Böhtlingk, kürzere Fassung). Tier A; Schmidt's Nachträge ride as A2 supplement.
_Avoid_: ultimate source (informal), Petersburg dict

**Authority tier**:
Weight class of a dictionary as witness for citation conventions: A Grundlagen, A2
supplement, B major scholarly references, C specialized/derived, D meta-indices.
_Avoid_: importance rank, quality score

**Origin axis**:
Provenance split of a dictionary: IND (Indian tradition) vs EUR (Western tradition,
including American works). Orthogonal to the authority tier.
_Avoid_: language family, nationality

**Patel census**:
Patel 2016's own per-dictionary convention assignments (dims 1–7); the witness
population displayed in census badges.
_Avoid_: gold set, annotation set

**Sub-rule**:
Patel's sub-convention group inside one convention (e.g. śatṛ vs vatup/matup within
dim 3); the flat majority is computed within a sub-rule, never across them.
_Avoid_: subgroup, option cluster

**Census badge**:
Tiered display of one option's census support: flat total, spelled-out Grundlagen sigla,
per-tier counts, IND/EUR split.
_Avoid_: dict count, vote count

**Conflict flag**:
Card-level warning shown when the Grundlagen back a non-majority census option; the
suggestion is never auto-switched (flag-never-flip).
_Avoid_: override, flip
